# 长江雨课堂心跳通信诊断（本地修复版）

> **状态：离线测试通过，未经过真实账号线上验收。** 本仓库用于检查本地程序的网络通信稳定性、服务器响应分类、视频时长解析及日志诊断。不可据此声称课程观看进度已获服务器确认。

## 内容

- `main.py`：来自用户原有程序的本地修复版（保留原有逻辑；包含自动化播放模拟代码，尚未进行实际服务端验证）。
- `test_雨课堂_心跳稳定性.py`：离线单元测试，不会连接雨课堂服务端。
- `changes.patch`：修复前后的差异补丁，便于代码审查。
- `FIXES.md`：修复范围与不支持事项。
- `requirements.txt`：Python 依赖。

## 自定义本地完成判定阈值

在本机的 `.env` 文件中添加：

```dotenv
COMPLETION_THRESHOLD=95
```

允许 0～100，默认 90，表示按服务器返回的观看进度判断是否达到本地设定的阈值。此设置只影响本地显示、跳过判断和统计，不修改雨课堂官方完成规则，也不会改变服务器保存的观看进度。设置错误时程序会明确报错。

## 本地离线验收

```bash
python -m pip install -r requirements.txt
python -m py_compile main.py
python test_雨课堂_心跳稳定性.py
```

测试只使用模拟 HTTP 响应；新增自定义阈值和非法输入的回归测试。不要将 HTTP 200 或本地计时器结束视作远端课程完成证明。
